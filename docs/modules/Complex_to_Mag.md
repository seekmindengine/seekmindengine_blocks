# Complex to Mag 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Complex to Mag

## 概览

Complex to Mag 模块将复数（Complex）输入信号转换为浮点（Float）幅度值。每个输出样本等于对应输入复数样本的模值 |a + bi| = √(a² + b²)。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Type Converters（类型转换） |
| Block ID | `blocks_complex_to_mag` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **信号幅度提取**  
   从 IQ 信号中提取幅度信息

2. **包络检测**  
   获取信号的幅度包络

3. **功率计算前置**  
   先提取幅度再平方得到瞬时功率

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | `complex` × 向量长度 | 连续样本流端口 |
| 输出 | `默认` | 样本流 | `float` × 向量长度 | 连续样本流端口 |

> 数据类型、向量长度和标签传播规则属于连接契约。即使流程可以启动，配置不一致仍可能造成错位或语义错误。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |

## 工作原理

```
输入: Complex (a + bi)
输出: Float √(a² + b²)

信号链路示例：
[复数采集源] → [Complex to Mag] → [低通滤波器] → [Sink]
              (提取幅度包络)
```

## 快速示例

**示例 1：复数采集信号包络提取**

```
[Source] → [Low Pass Filter] → [Complex to Mag] → [Audio Sink]
           (滤除高频)           (提取幅度)
```

**示例 2：信号强度监测**

```
[复数采集源] → [Complex to Mag] → [QT GUI Time Sink]
               (实时显示信号幅度)
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
