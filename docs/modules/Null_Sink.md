# Null Sink 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Null Sink

## 概览

Null Sink 模块接收输入数据但不做任何处理，直接丢弃。它类似于 Linux 中的 `/dev/null`，用于消耗不需要的输出流或在调试时作为占位输出目标。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Stream Operators（流操作） |
| Block ID | `blocks_null_sink` |
| 处理模型 | 连续样本流 |
| 典型位置 | Sink（数据终点） |
| 执行支持 | Python / C++ |

## 何时使用

1. **消耗多余输出**  
   连接不需要的输出端口，避免流程报错

2. **调试占位**  
   在搭建流程时临时放置，后续替换为实际处理或输出模块

3. **性能测试**  
   测试源端的产生数据速率

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |

> 数据类型、向量长度和标签传播规则属于连接契约。即使流程可以启动，配置不一致仍可能造成错位或语义错误。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Input Type** | 枚举 | 选择输入端样本类型 | Float | ✗ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |
| **Num Inputs** | 整数 | 设置输入端口数量 | 1 | ✗ |
| **Bus Connections** | 原始 | 设置复合端口的总线连接关系 | [[0,],] | ✗ |

## 工作原理

Null Sink 按调度器提供的节奏消费所有输入样本，但不保留数据、不生成输出，也不改变上游采样率。它可以终止一条暂时无需观察的支路，但不能替代限速、缓存或持久化组件。

## 快速示例

```
[Source] → [Some Processing] → [Null Sink]
                                 (丢弃结果)
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
