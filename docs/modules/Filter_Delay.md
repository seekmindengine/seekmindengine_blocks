# Filter Delay 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Filter Delay

## 概览

Filter Delay 将一条延时支路和一条实系数 FIR 滤波支路组合为复数输出。只接一路 Float 输入时，两条支路使用同一信号；接两路时，输入 0 形成实部，输入 1 经 FIR 滤波后形成虚部。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Filters（滤波器） |
| Block ID | `filter_delay_fc` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

- 将 FIR 滤波结果与对应的延时信号组合成复数流。
- 配置合适的相移滤波器系数，构造 I/Q 处理链。

模块只有 Taps 参数；延时由系数数量确定，不能独立设置任意 Delay。

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `0` | 样本流 | float | 必需，提供实部延时支路；单输入时也提供 FIR 支路 |
| 输入 | `1` | 样本流 | float | 可选，连接后作为 FIR 支路输入 |
| 输出 | `默认` | 样本流 | complex | 实部来自延时支路，虚部来自 FIR 支路 |

双输入时，两路 item 率应相同，样本位置应对应。输出 item 率等于每路输入的 item 率。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---|---|---|---|---|
| **Taps** | 实数向量 | 非空 FIR 系数列表，同时决定历史长度和实部支路的延时 | 需填写 | ✗ |

使用奇数长度、具有线性相位的系数时，两条支路可以具有相同的群延时。当前流程模板未提供 Taps 的运行时更新回调。

## 工作原理

设系数数量为 N。FIR 支路计算卷积后作为虚部；实部读取历史缓冲中的对应样本。对于奇数 N，实部延时为 `(N-1)/2` 个样本，与对称或反对称线性相位 FIR 的群延时一致。

```text
输入0 ── 延时 ────────── 实部 ┐
输入1（未接则用输入0）── FIR ─ 虚部 ┴→ complex 输出
```

偶数长度时，实部支路仍只能取整数样本延时，不能自动匹配半个样本的群延时。任意非线性相位系数也不保证两支路在所有频率上相位对齐。

## 快速示例

用 Float Vector Source 输出 `[1,2,3]`，Repeat=No，连接输入 0，输入 1 留空，Taps=`[1.0]`。将 Complex 输出保存到 File Sink，结果应为 `[1+1j,2+2j,3+3j]`。

再连接第二个 Float Vector Source，输出 `[4,5,6]`；Taps 保持不变，结果应为 `[1+4j,2+5j,3+6j]`。此例不引入历史延时，便于检查两路输入的作用。

## 性能与部署

FIR 运算量和历史缓冲随系数数量增长。较长系数带来启动瞬态；有限数据测试需要考虑滤波器尾部不会自动补零输出。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 输出类型无法连接 | 下游期待 float | 使用支持 complex 的下游 |
| 单输入时虚部不为零 | 同一输入也经过 FIR 支路 | 按 Taps 计算虚部预期值 |
| 两路相位未对齐 | 系数并非合适的奇数长度线性相位设计 | 检查系数、群延时和输入对齐 |
| 想单独调节延时 | 此模块没有 Delay 参数 | 采用专门的延时处理方案 |
