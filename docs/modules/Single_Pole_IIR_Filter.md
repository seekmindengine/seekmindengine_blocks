# Single Pole IIR Filter 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Single Pole IIR Filter

## 概览

Single Pole IIR Filter 是一个简单高效的一阶无限冲激响应（IIR）滤波器，也称为指数移动平均滤波器。它只有一个极点，计算效率极高，常用于平滑信号和简单的低通滤波。

## 何时使用

1. **信号平滑**  
   去除高频噪声，平滑信号

2. **移动平均**  
   实现指数加权移动平均

3. **包络跟踪**  
   跟踪信号的慢变包络

4. **AGC 控制**  
   自动增益控制中的平滑

## 工作原理

**差分方程：**
```
y[n] = α·x[n] + (1-α)·y[n-1]

其中：
- x[n]：输入样本
- y[n]：输出样本
- α：Alpha 参数
- y[n-1]：前一个输出
```

**系统函数：**
```
H(z) = α / (1 - (1-α)·z^(-1))
```

**频率响应：**

这是一个低通滤波器：
- DC（0 Hz）：增益 = 1
- 高频：增益衰减
- -3dB 截止频率与 Alpha 相关

每个向量元素有独立滤波状态。Alpha=1 时直通；Alpha=0 时保持上一输出，初始状态为 0。下面的时间常数公式适用于 0<Alpha<1。

**时间常数：**
```
τ = -1 / ln(1-α)  样本

对于小 α：
τ ≈ 1/α  样本
```

## Alpha 参数的影响

| Alpha | 时间常数 | 响应速度 | 平滑程度 | 适用场景 |
|-------|---------|---------|---------|---------|
| 0.01 | ~100 | 很慢 | 很强 | 强平滑 |
| 0.05 | ~20 | 慢 | 强 | 一般平滑 |
| 0.1 | ~10 | 中等 | 中等 | 平衡（示例值） |
| 0.2 | ~5 | 快 | 弱 | 快速响应 |
| 0.5 | ~2 | 很快 | 很弱 | 最小延迟 |

## 频率响应

**-3dB 截止频率：**

对于小 Alpha：
```
f_c ≈ α·f_s / (2π)

其中 f_s 是采样率
```

**示例：**
- 采样率 = 48 kHz
- Alpha = 0.1
- 截止频率 ≈ 764 Hz

**幅度响应：**
```
|H(f)| = α / sqrt(α² + 4(1-α)sin²(πf/f_s))
```

**相位响应：**

单极点滤波器引入相位延迟，但相对较小。

## 与 FIR 滤波器的比较

| 特性 | Single Pole IIR | FIR Filter |
|------|----------------|------------|
| 计算复杂度 | 极低（2次运算） | 高（N次运算） |
| 内存使用 | 极小（1个状态） | 大（N个状态） |
| 相位响应 | 非线性 | 可线性 |
| 稳定性 | 总是稳定 | 总是稳定 |
| 设计灵活性 | 低 | 高 |
| 适用场景 | 简单平滑 | 精确滤波 |

## 性能与部署

1. **计算效率**  
   - 每个样本只需 2 次运算（1 次乘法，1 次加法）
   - CPU 使用率极低
   - 适合实时应用

2. **内存使用**  
   - 只需存储 1 个前一输出值
   - 内存占用最小

3. **延迟**  
   - 群延迟约为 (1-α)/α 个样本
   - 相位延迟随频率变化

4. **数值稳定性**  
   - 对于 0 < α ≤ 1，滤波器总是稳定的
   - 长时间运行无数值问题

## 故障排查

**Q1: 如何选择 Alpha 值？**  
A: 根据需要的平滑程度。更小的 Alpha 提供更强的平滑但响应更慢。

**Q2: 可以实现高通滤波吗？**  
A: 不能直接实现。Single Pole IIR 是低通滤波器。高通需要其他结构。

**Q3: 与 Moving Average 有什么区别？**  
A: Single Pole IIR 是指数加权，旧样本影响逐渐衰减。Moving Average 是均匀加权。

**Q4: 如何计算截止频率？**  
A: 对于小 Alpha：f_c ≈ α·f_s/(2π)。精确值需要求解频率响应方程。

**Q5: 会引入多大延迟？**  
A: 群延迟约 (1-α)/α 个样本。例如 α=0.1 时，延迟约 9 个样本。

**Q6: 可以级联使用吗？**  
A: 可以，级联多个单极点滤波器可以获得更陡峭的滚降。

**Q7: 如何设计特定截止频率的滤波器？**  
A: 使用公式 α ≈ 2πf_c/f_s（对于小 Alpha）。

## 设计示例

**设计 100 Hz 低通滤波器（采样率 48 kHz）：**

```
f_c = 100 Hz
f_s = 48000 Hz

α ≈ 2π·f_c / f_s
  = 2π·100 / 48000
  ≈ 0.0131
```

配置：
- Alpha: 0.013
- 实际截止频率约 100 Hz

## 数学背景

**冲激响应：**
```
h[n] = α·(1-α)^n·u[n]

其中 u[n] 是单位阶跃函数
```

这是一个指数衰减序列。

**阶跃响应：**
```
s[n] = 1 - (1-α)^(n+1)
```

输出逐渐接近输入，速度由 Alpha 控制。

**稳态误差：**

对于常数输入，稳态输出等于输入（无误差）。
