# Streams to Vector 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Streams to Vector

## 概览

Streams to Vector 模块将多路独立的标量输入流合并为单路向量输出流。每个输入流的一个样本被组合成输出向量中的一个元素。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Stream Operators（流操作） |
| Block ID | `blocks_streams_to_vector` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **多通道数据合并**  
   将多个传感器通道的数据合并为向量格式

2. **FFT 前准备**  
   为向量处理模块（如 FFT）准备输入数据

3. **波束成形**  
   将传感器阵列各通道数据合并为阵列向量

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |
| 输出 | `默认` | 样本流 | 由数据类型、向量长度和流数量参数决定 | 连续样本流端口；端口数量由参数决定 |

> 数据类型、向量长度和标签传播规则属于连接契约。即使流程可以启动，配置不一致仍可能造成错位或语义错误。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **IO Type** | 枚举 | 选择输入输出样本类型，连接两端必须一致 | float | ✗ |
| **Num Streams** | 整数 | 设置并行样本流数量 | 2 | ✗ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |

## 工作原理

```
输入0: [a0, a1, a2, ...]
输入1: [b0, b1, b2, ...]
输入2: [c0, c1, c2, ...]

输出: [[a0, b0, c0], [a1, b1, c1], [a2, b2, c2], ...]
```

## 快速示例

**示例 1：多通道合并后送入 FFT**

```
[Channel 0] ──┐
[Channel 1] ──┼── [Streams to Vector (N=4)] → [FFT] → [Sink]
[Channel 2] ──┤
[Channel 3] ──┘
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
