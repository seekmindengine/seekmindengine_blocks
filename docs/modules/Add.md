# Add 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Add

## 概览

Add 模块将多个输入流的样本逐个相加，输出求和后的单路信号。支持多种数据类型和向量运算，是信号合成与混频中最基础的模块之一。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Math Operators（数学运算） |
| Block ID | `blocks_add_xx` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **信号叠加**  
   将多路信号合并为一路

2. **噪声注入**  
   在信号中添加噪声

3. **多通道混合**  
   混合多路声学或振动传感器信号

4. **向量求和**  
   对向量数据进行逐元素相加

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |
| 输出 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口 |

> 连接前核对数据类型、向量长度、采样率语义和端口数量；首次运行使用可观察的 Sink 验证结果。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **IO Type** | 枚举 | 选择输入输出样本类型，连接两端必须一致 | float | ✗ |
| **Num Inputs** | 整数 | 设置输入端口数量 | 2 | ✗ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |

## 参数说明

**1. IO Type**
- I/O 数据类型
  - complex
  - float
  - int
  - short

**2. Num Inputs**
- 输入数量

**3. Vector Length**
- 向量长度

## 工作原理

```
输入1 ──┐
输入2 ──┤── 求和 ── 输出
输入3 ──┘

输出[n] = 输入1[n] + 输入2[n] + 输入3[n] + ...
```

## 快速示例

**示例 1：两路信号叠加**

```
[Signal Source 1] ──┐
                    ├── [Add] ── [Output]
[Signal Source 2] ──┘
```

**示例 2：信号加噪声**

```
[Signal Source] ──┐
                  ├── [Add] ── [Sink]
[Noise Source] ──┘
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
