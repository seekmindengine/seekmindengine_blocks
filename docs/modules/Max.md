# Max 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Max

## 概览

Max 模块从多个输入流中逐样本比较，输出每个位置上的最大值。支持向量模式，可输出整体最大值或逐元素最大值。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Math Operators（数学运算） |
| Block ID | `blocks_max_xx` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **信号峰值检测**  
   从多路信号中提取最大值

2. **比较通道测量值**  
   在上游已计算的幅度或功率中选取最大值

3. **向量最大值**  
   对向量数据逐元素取最大值

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |
| 输出 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口 |

> 连接前核对数据类型、向量长度、采样率语义和端口数量；首次运行使用可观察的 Sink 验证结果。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **IO Type** | 枚举 | 选择输入输出样本类型，连接两端必须一致 | float | ✗ |
| **Num Inputs** | 整数 | 设置输入端口数量 | 1 | ✗ |
| **Input Vector Length** | 整数 | 设置输入向量的元素数量 | 1 | ✗ |
| **Output Vector Length** | 整数 | 只能为 1 或等于 Input Vector Length | 1 | ✗ |

## 参数说明

**1. IO Type**
- I/O 数据类型
  - float
  - int
  - short

**2. Num Inputs**
- 输入数量

**3. Input Vector Length**
- 每个输入数据项包含的元素数量，必须与上游向量长度一致。
**4. Output Vector Length**
- 为 1 时，每轮在全部输入向量中取一个最大值；等于输入向量长度时，按对应元素位置跨输入取最大值。其他长度不受支持。
## 工作原理

```
标量模式 (vlen=1, vlen_out=1):
  输入1 ──┐
  输入2 ──┤── 比较 ── 输出最大值
  输入3 ──┘

向量模式 (vlen=N, vlen_out=N):
  输出[n] = max(输入1[n], 输入2[n], 输入3[n], ...)
```

## 快速示例

**示例 1：两路信号取最大值**

```
[Signal 1] ──┐
              ├── [Max] ── [Sink]
[Signal 2] ──┘
```

**示例 2：向量逐元素最大值**

```
[Vector Input 1] ──┐
                    ├── [Max (Input Vector Length=64, Output Vector Length=64)] ── [Sink]
[Vector Input 2] ──┘
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
