# FFT Filter 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / FFT Filter

## 概览

FFT Filter 通过 FFT 实现时域 FIR 卷积，适合较长系数列表。输入和输出都是时域样本流；Taps 是时域冲激响应，不能直接填入频谱采样值。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Filters（滤波器） |
| Block ID | `fft_filter_xxx` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

- 使用已设计好的长 FIR 系数处理连续信号。
- 在滤波后按整数倍抽取。

它不会自动估计或更新滤波系数；需要自适应滤波时，应另行提供系数更新逻辑。

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型参数决定 | 连续样本流端口 |
| 输出 | `默认` | 样本流 | 由数据类型参数决定 | 连续样本流端口 |

> 滤波设计采样率应与系数作用的处理段一致；抽取型按抽取前、插值型按插值后采样率设计，并用已知信号验证频响。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Type** | 枚举 | 选择样本数据类型，必须与相连端口一致 | Float->Float (Real Taps) | ✗ |
| **Decimation** | 整数 | 设置抽取倍数；输出速率为输入速率除以该值 | 1 | ✗ |
| **Taps** | 类型相关 | 设置滤波器抽头系数 |  | ✓ |
| **Sample Delay** | 整数 | 声明用于标签位置调整的样本延时 | 0 | ✗ |
| **Num. Threads** | 整数 | 设置处理线程数量；增加前应测量吞吐与调度开销 | 1 | ✓ |

## 工作原理

实现采用重叠相加法（Overlap-Add）：输入按块补零，执行 FFT，与系数的 FFT 相乘，再作逆变换。保留卷积尾部并加到下一块的起始位置，使分块结果等价于连续 FIR 卷积。

若 Decimation=D，输出 item 率为输入的 1/D。系数必须在抽取前限制带宽，以避免混叠。模块根据系数长度选择内部 FFT 大小；它没有独立的 FFT Size 参数。

Sample Delay 用于向调度器声明样本延时以调整标签位置，不是额外插入一段样本延时。对称 N 抽头 FIR 的群延时为 `(N−1)/2` 个输入样本，此外还有分块处理带来的等待时间。

## 快速示例

Type=Float->Float (Real Taps)、Decimation=1、Taps=`[0.5,0.5]`。Float Vector Source 输出一个 1，后接至少 4095 个 0，Repeat=No，连接 FFT Filter 与 Float File Sink。输出开头应接近 `[0.5,0.5,0,0,…]`；浮点误差可能产生很小的非零值。

使用较长零尾巴是为了满足内部按块调度的输入需求。有限输入的尾部卷积不保证自动补零输出，需要时应在上游显式补齐。

## 性能与部署

性能取决于系数长度、内部 FFT 大小、类型及线程设置。长滤波器可能比直接 FIR 更省计算，但不存在适用于所有设备的固定抽头数分界；使用实际输入率测量吞吐和延时。Num. Threads 控制 FFT 计算线程，增加线程不保证提速。

## 故障排查

| 现象 | 检查点 | 处理方式 |
|---|---|---|
| 有限短序列没有输出 | 不足一个内部处理块 | 延长输入并显式补零 |
| 抽取后出现折叠频率 | Taps 未满足抗混叠要求 | 按输出奈奎斯特频率设计低通 |
| 延时或标签位置不符 | 混淆群延时、分块等待与 Sample Delay | 分别测量并设置标签延时声明 |
| 频响不符 | 将频谱值误作 Taps | 填入时域 FIR 系数 |
