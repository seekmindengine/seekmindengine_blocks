# Wav File Sink 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Wav File Sink

## 概览

Wav File Sink 将 Float 音频流编码并写入带格式信息的文件，支持面板列出的 WAV、FLAC、Ogg 和 64-bit WAV。输出容器及编码能力以当前运行包支持为准。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | File Operators（文件操作） |
| Block ID | `blocks_wavfile_sink` |
| 处理模型 | 连续样本流 |
| 典型位置 | Sink（数据终点） |
| 执行支持 | Python / C++ |

## 何时使用

1. **音频录制**  
   录制音频信号到标准 WAV 文件

2. **处理结果保存**  
   保存声学处理或检测后的音频

3. **音频处理结果**  
   保存音频处理算法的输出

4. **数据交换**  
   与其他音频软件交换数据

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | `float` | 连续样本流端口；端口数量由参数决定 |

> 文件格式通常不携带完整流程元数据。读写两端应记录并复用数据类型、采样率、通道数和字节序配置。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **File** | file_save | 设置读取或写入的文件路径 |  | ✓ |
| **N Channels** | 整数 | 设置并行通道数量 | 1 | ✗ |
| **Sample Rate** | 整数 | 设置采样率，单位为 Sps | 32000 | ✗ |
| **Output Format** | 枚举 | 选择 Output Format 的工作模式 | WAV | ✗ |
| **Bits per Sample** | 枚举 | 设置每个样本包含的有效位数 | 16-bit | ✗ |
| **Bits per Sample** | 枚举 | 设置每个样本包含的有效位数 | 16-bit | ✗ |
| **Codec** | 枚举 | 选择音频或媒体编码格式 | Vorbis | ✗ |
| **Bits per Sample** | 枚举 | 设置每个样本包含的有效位数 | 16-bit | ✗ |
| **Append to existing file** | 枚举 | 控制启动时追加写入还是覆盖目标文件 | No | ✗ |

## 工作原理

将各路 Float 样本交织后交给音频文件接口写入。Sample Rate 只用于文件采样率信息，不会重采样或限制输入速度。整数 PCM 使用归一化幅度约定，建议保持在 [-1,1] 内并预留峰值余量；浮点格式则保存浮点数据，不能一概视为整数转换。

Bits per Sample 在不同 Output Format 下显示不同选项；Ogg 使用 Codec。追加已有文件时，采样率、声道数、容器与编码必须一致。正常停止并关闭文件后再交给其他软件读取。

## 快速示例

两路 48 kHz Float 信号分别接输入 0、1；N Channels=2、Sample Rate=48000、Output Format=WAV、对应 Bits per Sample=16-bit、Append to existing file=No。停止流程后检查文件声道数和时长；每声道写入 48000 个样本对应 1 秒。

如果输入原为 192 kHz，应先重采样到 48 kHz。仅把文件的 Sample Rate 改成 48000 会改变播放速度和音高。

## 性能与部署

未压缩 PCM 数据率约为“采样率 × 声道数 × 每样本字节数”，另加文件头。压缩格式的数据率取决于编码与内容，不能用固定压缩倍数估算容量。持续记录应检查磁盘写入速度与文件关闭结果。

## 故障排查

| 现象 | 检查点 | 处理方式 |
|---|---|---|
| 追加失败 | 目标文件格式参数不一致或不存在 | 检查已有文件信息与追加配置 |
| 播放速度不对 | 文件采样率与输入实际速率不同 | 先重采样再写入 |
| 声音失真 | 输入幅度超出整数编码范围 | 降低增益并检查峰值 |
| 格式组合被拒绝 | 容器与编码不匹配或运行包不支持 | 使用面板对应选项，先测试 PCM WAV |
| 文件尾部不完整 | 流程未正常停止关闭 | 正常停止后核对样本数和时长 |
