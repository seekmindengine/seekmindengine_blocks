# GLFSR Source 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / GLFSR Source

## 概览

GLFSR Source 用伽罗瓦反馈移位寄存器产生可重复的伪随机 bit 序列。选择本原反馈多项式与非零初态时可获得最大长度序列；任意自定义 Mask 并不保证最大周期。

## 何时使用

1. **编码激励与相关检测**  
   生成伪随机码（PN码）用于主动声学测试或相关检测

2. **加扰/解扰**  
   数字链路实验中的数据加扰

3. **测试序列**  
   生成已知的伪随机测试模式

4. **同步序列**  
   用于帧同步和定时恢复

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Type** | 枚举 | 选择样本数据类型，必须与相连端口一致 | float | ✗ |
| **Degree** | 整数 | 设置生成序列所用多项式的阶数 |  | ✗ |
| **Repeat** | 枚举 | 控制一个设定周期结束后是否继续生成 | Yes | ✗ |
| **Mask** | 整数 | 设置参与位运算的掩码 | 0 | ✗ |
| **Seed** | 整数 | 设置随机数种子；固定值可复现实验结果 | 1 | ✗ |

## 工作原理

每次输出寄存器最低位，将寄存器右移一位；原最低位为 1 时，再与 Mask 异或。Byte 输出为 0/1，Float 输出为 `2×bit−1`，即 −1/+1。

Mask=0 时按 Degree 使用预设掩码。预设表覆盖 1–32 阶；例如 Degree=3 对应 0x5，7 对应 0x41，15 对应 0x4001，31 对应 0x40000004。不同移位方向的多项式表示不能直接混用。

非零有效初态和本原掩码下，周期为 `2^Degree−1`。Seed=0 会锁在全零状态，对应 Byte 恒为 0、Float 恒为 −1。Repeat=No 输出 `2^Degree−1` 个 item 后结束，Repeat=Yes 持续生成。

## 快速示例

设置 Type=Byte、Degree=3、Mask=0、Seed=1、Repeat=No，连接 Byte File Sink。按当前右移实现，应得到 `[1,1,1,0,1,0,0]` 共 7 个 bit item。改成 Float 时，同一序列为 `[1,1,1,-1,1,-1,-1]`。

## 性能与部署

生成过程只需移位与异或，仍应按目标 item 率测量开销。较大 Degree 会使完整周期验证耗时显著增加；先用小阶数验证位序和初态，再扩大规模。

## 故障排查

| 现象 | 检查点 | 处理方式 |
|---|---|---|
| 输出恒定 | Seed=0 或无效反馈 | 使用非零初态和预设 Mask |
| 周期短于预期 | Mask 不是对应阶数的本原反馈 | 先使用 Mask=0 验证 |
| 与外部序列相反或错位 | 输出映射、移位方向或初态不同 | 用 3 阶示例对照 |
| 提前结束 | Repeat=No | 按所需有限长度或持续输出配置 |
