# Head 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Head

## 概览

Head 模块从输入流中仅输出指定数量的样本，之后停止数据传输。它类似于 GNU/Linux 中 `head` 命令的功能，适用于有限数据采集和流程调试场景。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Stream Operators（流操作） |
| Block ID | `blocks_head` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **有限数据采集**  
   仅采集指定数量的样本后停止

2. **流程调试**  
   限制数据量以便分析流程行为

3. **测试数据截取**  
   从连续信号中截取固定长度的数据段

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口 |
| 输出 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；可选 |

> 数据类型、向量长度和标签传播规则属于连接契约。即使流程可以启动，配置不一致仍可能造成错位或语义错误。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Type** | 枚举 | 选择样本数据类型，必须与相连端口一致 | float | ✗ |
| **Num Items** | 整数 | 设置每次处理的条目数量 | 1024 | ✓ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |

## 参数说明

**1. Type**
- 数据类型
  - complex
  - float
  - int
  - short
  - byte

**2. Num Items**
- 元素数量

**3. Vector Length**
- 向量长度

## 工作原理

```
输入流 ── [Head (N=1024)] ── 输出前 1024 个样本 ── 停止
```

## 快速示例

**示例 1：采集 1 秒数据**

```
[Source (采样率 1MHz)] → [Head (N=1000000)] → [File Sink]
                          (采集 1M 样本 = 1秒)
```

**示例 2：调试流程**

```
[Signal Source] → [Filter Chain] → [Head (N=10000)] → [QT GUI Time Sink]
                                    (仅显示前 10000 个样本)
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
