# Keep One In N 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Keep 1 in N

## 概览

Keep One In N 模块对输入流进行等间隔抽样，每接收 N 个样本仅输出 1 个，其余丢弃。适用于降低数据速率、降采样显示和简化后端处理。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Stream Operators（流操作） |
| Block ID | `blocks_keep_one_in_n` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **数据降速**  
   降低高速数据流的处理负担

2. **显示降采样**  
   在 GUI 显示前降低刷新率

3. **抽取分析**  
   每隔固定间隔采集一个样本用于统计

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口 |
| 输出 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口 |

> 数据类型、向量长度和标签传播规则属于连接契约。即使流程可以启动，配置不一致仍可能造成错位或语义错误。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Type** | 枚举 | 选择样本数据类型，必须与相连端口一致 | Float | ✗ |
| **N** | 整数 | 设置算法使用的 N 值，必须为正整数 | 1 | ✓ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |

## 参数说明

**1. Type**
- 数据类型
  - **Complex**：complex
  - **Float**：float
  - **Int**：int
  - **Short**：short
  - **Byte**：byte

**2. N**
- 每 N 个输入项保留一个；必须为正整数。
**3. Vector Length**
- 向量长度

## 工作原理

```
输入: [s0, s1, s2, s3, s4, s5, s6, s7, ...]
N = 3
输出: [s2, s5, s8, ...]
```

计数从 N 开始，每读一个 item 减 1，到 0 才保留。因此从零编号的首次保留位置是 N−1；运行时修改 N 会重置计数相位。向量输入时按整个向量 item 取舍。

模块不执行抗混叠滤波，输出 item 率是输入的 1/N；显示模块的采样率也需相应调整。

## 快速示例

**示例 1：减少送往 GUI 的样本量**

```
[High Rate Source] → [Keep One In N (N=100)] → [QT GUI Time Sink]
                      (降低刷新负担)
```

**示例 2：间歇数据记录**

```
[Sensor Source] → [Keep One In N (N=1000)] → [File Sink]
               (每 1000 个样本记录 1 个)
```

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
