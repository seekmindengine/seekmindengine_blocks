# DC Blocker 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / DC Blocker

## 概览

DC Blocker 利用滑动平均支路与延时支路相减，抑制直流及附近的低频分量。适用于去除采集偏置；需要保留极低频测量信息时，应先核对它的幅频响应。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Filters（滤波器） |
| Block ID | `dc_blocker_xx` |
| 处理模型 | 连续样本流 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

- 去除传感器、音频或复数基带中的恒定偏置。
- 在频谱观察前抑制零频尖峰。

它会同时影响直流附近的信号，不能用于要求保留绝对直流值的测量。

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型参数决定 | 连续样本流端口 |
| 输出 | `默认` | 样本流 | 由数据类型参数决定 | 连续样本流端口 |

> 滤波设计采样率应与系数作用的处理段一致；抽取型按抽取前、插值型按插值后采样率设计，并用已知信号验证频响。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---|---|---|---|---|
| **Type** | 枚举 | Float→Float 或 Complex→Complex | Float->Float | ✗ |
| **Length** | 整数 | 滑动平均长度 D，使用正整数；通常从 32 起调 | 32 | ✗ |
| **Long Form** | 枚举 | Yes 使用四级平均结构，No 使用两级；影响通带平坦度与延时 | Yes | ✗ |

## 工作原理

设长度 D 的滑动平均为 `A(z)=(1+z⁻¹+…+z⁻⁽ᴰ⁻¹⁾)/D`：

- Short Form：`H(z)=z⁻⁽ᴰ⁻¹⁾−A(z)²`，群延时为 D−1 个样本。
- Long Form：`H(z)=z⁻⁽²ᴰ⁻²⁾−A(z)⁴`，群延时为 2D−2 个样本，通带更平坦。

两者在直流处的理论增益均为零。增大 D 会使直流附近的抑制带变窄，并增加延时；不能把 D 简单理解为“越大，直流抑制越强”。启动时历史缓冲未填满，会有瞬态。

## 快速示例

Float Vector Source 使用全 1 序列、Repeat=Yes，连接 Length=32、Long Form=Yes 的 DC Blocker，再经限速与 QT GUI Time Sink 观察。启动瞬态过后，输出应接近 0。然后改用“直流偏置 + 正弦波”，比较处理前后的均值与正弦幅度；保留至少数倍 D 的样本来观察稳定段。

## 性能与部署

滑动平均采用递推计算，历史缓冲随 D 增加。Long Form 使用更多状态，Length=32 时群延时为 62 个输入样本；Short Form 为 31 个。多路对比时应补偿延时。

## 故障排查

| 现象 | 原因或检查点 | 处理方式 |
|---|---|---|
| 启动时有脉冲 | 历史缓冲初始为零 | 先观察稳定段 |
| 有用低频衰减 | 信号落在直流附近抑制带 | 增大 D 后测量响应，或另行设计滤波器 |
| 两路时序不齐 | 未补偿群延时 | 按所选结构和 D 对齐 |
| 输出不再反映绝对基线 | 直流已被去除 | 需要绝对值时保留原始数据支路 |
