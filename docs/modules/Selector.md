# Selector 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Selector

## 概览

Selector 模块从多个输入流中选择一路或多路输出，可通过参数或消息动态切换选择的通道。适用于信号路由、A/B 比较和多通道切换场景。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | Misc（其他） |
| Block ID | `blocks_selector` |
| 处理模型 | 连续样本流与消息 |
| 典型位置 | Transform（处理与变换） |
| 执行支持 | Python / C++ |

## 何时使用

1. **信号路由**  
   在多路信号中动态选择一路进行处理

2. **A/B 比较**  
   在两路信号间快速切换进行对比

3. **多通道监测**  
   轮流查看多路输入通道

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输入 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |
| 输入 | `en` | 消息 | `按消息格式` | 离散消息端口；可选 |
| 输入 | `iindex` | 消息 | `按消息格式` | 离散消息端口；可选 |
| 输入 | `oindex` | 消息 | `按消息格式` | 离散消息端口；可选 |
| 输出 | `默认` | 样本流 | 由数据类型和向量长度参数决定 | 连续样本流端口；端口数量由参数决定 |

> 连接前核对数据类型、向量长度、采样率语义和端口数量；首次运行使用可观察的 Sink 验证结果。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **Type** | 枚举 | 选择样本数据类型，必须与相连端口一致 | float | ✗ |
| **Enabled** | 枚举 | 控制 Block 是否转发数据 | Enabled | ✓ |
| **Number of Inputs** | 整数 | 设置输入端口数量 | 2 | ✗ |
| **Number of Outputs** | 整数 | 设置输出端口数量 | 2 | ✗ |
| **Input Index** | 整数 | 选择当前接通的输入端口索引 | 0 | ✓ |
| **Output Index** | 整数 | 选择当前接通的输出端口索引 | 0 | ✓ |
| **Vector Length** | 整数 | 设置每个向量包含的元素数量 | 1 | ✗ |
| **Show Msg Ports** | 枚举 | 控制是否显示运行时控制消息端口 | No | ✗ |

## 参数说明

**1. Type**
- 数据类型
  - complex
  - float
  - int
  - short
  - byte

**2. Enabled**
- 是否启用
  - **Enabled**：True
  - **Disabled**：False

**3. Number of Inputs**
- 输入数量

**4. Number of Outputs**
- 输出数量

**5. Input Index**
- 输入索引

**6. Output Index**
- 输出索引

**7. Vector Length**
- 向量长度

**8. Show Msg Ports**
- 是否显示消息端口
  - **Yes**：False
  - **No**：True

## 工作原理

```
输入0 ──┐
输入1 ──┤── [选择 Input Index] ── 输出
输入2 ──┘
```

## 快速示例

**示例 1：两路信号切换**

```
[Signal A] ── 输入0 ──┐
                       ├── [Selector] ── [Sink]
[Signal B] ── 输入1 ──┘
```

设置 Input Index = 0 输出 Signal A，Input Index = 1 输出 Signal B。

## 性能与部署

在目标采样率和数据规模下验证 CPU、内存与端到端延迟。动态参数、向量长度和并行通道增加时应重新测量。

## 故障排查

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 流程无法连接 | 数据类型、向量长度或端口数量不匹配 | 对照“输入与输出”统一连接契约 |
| 运行结果异常 | 采样率语义或关键参数不一致 | 使用确定性输入，从默认参数逐项验证 |

更多通用排查方法见[故障排查指南](../TROUBLESHOOTING.md)。
