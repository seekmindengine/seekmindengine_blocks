# Wav File Source 模块

[文档首页](../../README.md) / [Block 目录](../../README.md#block-目录) / Wav File Source

## 概览

Wav File Source 通过音频文件接口读取 WAV 等文件，按声道输出 Float 样本。可读格式取决于运行包中的音频文件库；本页以 WAV 为可复现配置。

## 模块信息

| 项目 | 内容 |
|---|---|
| 分类 | File Operators（文件操作） |
| Block ID | `blocks_wavfile_source` |
| 处理模型 | 连续样本流 |
| 典型位置 | Source（数据源） |
| 执行支持 | Python / C++ |

## 何时使用

1. **音频文件播放**  
   读取并播放 WAV 音频文件

2. **音频信号处理**  
   对录制的音频进行离线处理

3. **测试数据源**  
   使用预录制的音频作为测试输入

4. **回放实验**  
   读取音频文件用于处理链路验证

## 输入与输出

| 方向 | 端口 | 模型 | 数据类型 | 说明 |
|---|---|---|---|---|
| 输出 | `0 .. N Channels−1` | 样本流 | float | 每个端口对应文件中的一个声道 |

N Channels 是编辑器中的输出数量，必须不大于文件实际声道数。只连接较少声道时，后续声道被忽略；不会混音成单声道。

## 参数

| 参数名称 | 类型 | 说明 | 默认值 | 运行时可调 |
|---------|------|------|--------|-----------|
| **File** | file_open | 设置读取或写入的文件路径 |  | ✗ |
| **Repeat** | 枚举 | 控制到达文件末尾后是否从头继续读取 | Yes | ✗ |
| **N Channels** | 整数 | 设置并行通道数量 | 1 | ✗ |

## 工作原理

模块读取文件头并将交织声道数据拆成各自的 Float 流。整数 PCM 通常归一化到约 [-1,1]；浮点音频文件可包含超出该范围的值。文件采样率不会自动写入流程变量，也不会自动配置 Audio Sink 或显示模块。Repeat=No 时读到末尾结束该数据源；Repeat=Yes 时回到文件起点。

## 快速示例

准备一个 48 kHz 双声道 WAV，File 选择该文件，N Channels=2，Repeat=No。将两路输出接到配置为 48 kHz、双声道的音频播放设备。仅查看波形时，使用相应速率的 Throttle 与 QT GUI Time Sink；离线文件处理可不限速运行。

## 性能与部署

文件读取速度由磁盘、解码与下游消费能力共同决定。播放时按文件实际采样率配置设备；需要改变采样率时显式加入重采样模块。循环文件的首尾不连续可能产生瞬态。

## 故障排查

| 现象 | 检查点 | 处理方式 |
|---|---|---|
| 无法打开文件 | 路径、空文件、格式或当前解码支持 | 先用已知有效 PCM WAV 排查 |
| 音高或时间轴错误 | 下游采样率不等于文件采样率 | 手动核对文件信息并配置 |
| 立体声只有一路 | N Channels=1 | 改为 2 并连接两个输出 |
| 多声道构造失败 | 请求声道数超过文件声道数 | 按文件实际声道数设置 |
